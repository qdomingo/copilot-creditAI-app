┌──────────────────────────────────────────────────────────────────────────────┐
│                         🚀 PRIMEROS PASOS RÁPIDOS                            │
└──────────────────────────────────────────────────────────────────────────────┘

  1️⃣  INSTALAR
      Windows:  install.bat
      Linux:    chmod +x install.sh && ./install.sh

  2️⃣  CONFIGURAR
      Editar .env:
      GITHUB_TOKEN=ghp_tu_token_aqui
      GITHUB_ORG=tu_organizacion

  3️⃣  EJECUTAR
      Windows:  run_app.bat
      Linux:    ./run_app.sh

  4️⃣  USAR
      1. Abre http://localhost:8501
      2. Carga tu Excel de usuarios
      3. Conecta a GitHub
      4. ¡Empieza a monitorear!

┌──────────────────────────────────────────────────────────────────────────────┐
│                         ⚠️ ANTES DE EMPEZAR                                  │
└──────────────────────────────────────────────────────────────────────────────┘

  📝 Necesitarás:
     1. Python 3.9 o superior instalado
     2. Token de GitHub con permisos adecuados
     3. Permisos de admin en tu organización GitHub
     4. Excel con datos de usuarios (o usar el ejemplo)

  🔑 Obtener Token GitHub:
     1. GitHub → Settings → Developer settings
     2. Personal access tokens → Generate new token
     3. Seleccionar scopes: read:org, read:user, copilot
     4. Copiar y guardar en .env
